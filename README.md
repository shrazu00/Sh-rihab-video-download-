# SH-RIHAB 🚀

A Powerful Python Downloader Tool for Termux. Download YouTube Videos, TikTok Videos (No Watermark), and MP3 Audio easily.

## Installation & Usage :

```bash
pkg update -y && pkg upgrade -y
pkg install python ffmpeg git -y
pip install yt-dlp
git clone https://github.com/shrazu00/Sh-rihab-video-download-.git
cd Sh-rihab-video-download-
python sh_rihab.py
